# 8요소 라벨링 기준 (개정판)

> 개정 배경: 초기 라벨링에서 검수자 간 일치도(kappa)가 낮았음
> (특히 CONTEXT 0.070, FORMAT 0.179, CONSTRAINT 0.233). 원인은 "문장에 요소가
> 없으면 무조건 누락(1)"이라는 모호한 기준이었음. 아래 개정 기준으로 통일한다.

## 핵심 원칙

**판정은 "문장에 있냐/없냐"가 아니라 "요청 수행에 보완이 필요하냐"로 한다.**

- **1 = 보완 필요** — 이 요소가 없으면 적절한 결과를 만들기 어려움
- **0 = 충분/불필요** — 명시됐거나, **없어도 이 요청엔 굳이 필요 없음**

> ⚠️ 없음 ≠ 무조건 누락. 문장에 요소가 없어도 그 요소가 불필요하면 **0**.
> 예) "번역 좀"에서 Context(배경)는 번역 작업에 굳이 필요 없으므로 **0**.

## 요소별 판정 기준

| 요소 | 정의 | 1 (보완 필요) 예 | 0 (충분/불필요) 예 |
|------|------|-----------------|-------------------|
| **Task** | 무엇을 요청하는지 | "이거 좀 해줘" — 작업 자체가 불명확 | "회의 내용 요약해줘" — 작업 명확 |
| **Audience** | 결과물을 보는 대상 | 대상에 따라 표현이 달라져야 하는데 대상이 없음 | 대상 명시됨, 또는 대상이 결과에 안 중요 |
| **Context** | 배경·상황 | 배경이 없으면 적절한 결과가 어려움 | 상황 제공됨, 또는 단순 요청이라 배경 불필요 |
| **Format** | 출력 형식 | 결과 구조가 중요한데 형식 지정 없음 | 표·목록·메일 등 형태가 드러남 |
| **Tone** | 어조·말투 | 말투가 중요한데 톤이 불명확 | 정중/친근 등 명시됨, 또는 톤 지정 불필요 |
| **Length** | 글자 수·분량 | 분량이 중요한데 길이 기준 없음 | 500자·3문단 등 있음, 또는 길이 지정 불필요 |
| **Constraint** | 제약 조건 | 지켜야 할 포함/제외 조건이 필요한데 없음 | 제약 명시됨, 또는 특별한 제약 불필요 |
| **Example** | 참고 예시·샘플 | 특정 스타일 재현에 예시가 필요함 | 예시 주어짐, 또는 예시가 굳이 불필요 |

## 자주 헷갈리는 구분

| 구분 | A | B |
|------|---|---|
| **Format vs Example** | Format = 결과 구조/형태 (표·메일) | Example = 따라갈 실제 참고 샘플 |
| **Format vs Length** | Format = 표/메일/목록 | Length = 글자 수/문단 수/개수 |
| **Context vs Constraint** | Context = 왜/어떤 상황인지 | Constraint = 반드시 지켜야 할 조건 |
| **Audience vs Tone** | Audience = 누구에게 | Tone = 어떤 말투로 |

## 라벨링 절차

1. 각자 자신의 시트만 작성 (다른 사람 값 먼저 안 봄)
2. 각 문장의 8요소를 0/1로 판정, 애매하면 메모에 이유 기록
3. 30문장 완료 후, **불일치 문장을 모아 기준을 재조정**하고 최종 Ground Truth 확정

> 목적은 "정답을 빨리 맞히기"가 아니라 **어디서 판단이 갈리는지 찾는 것**.
> 특히 Audience·Context·Tone·Constraint·Example은 "없어도 충분한 경우"가 있으므로
> 이유를 생각하고 판정한다.

## 데이터 파이프라인 영향 (병환 담당)

이 기준은 **학습 데이터의 정답(Ground Truth) 기준**이다. 데이터 담당(병환)은:

- 합성 데이터 생성 시 이 기준으로 라벨을 부여
- 기존 gold 라벨을 새 기준으로 재검토 (특히 번역·요약·다듬기 작업의 CONTEXT·EXAMPLE·LENGTH)
- 재라벨링 후 kappa 재측정 → CONTEXT·FORMAT·CONSTRAINT 일치도 개선 확인

목업 코드(`ai-service/app/services/diagnose_mock.py`)도 이 기준을 규칙으로 반영했다
(작업별 불필요 요소는 없어도 0). 승득이 KcELECTRA로 교체할 때도 이 기준의
라벨로 학습해야 한다.
